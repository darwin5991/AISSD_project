# Verification specification and acceptance
Main objective: actual checkpoint MNIST inference, bit-exact independent integer reference, not exhaustive exception coverage. All new integration outputs through assembly writes to external DMEM; no internal direct dump. Only valid inputs. Failures block next gate unless diagnosed/repaired under 07.

## 0. Preflight and basic tests
- Confirm exact baseline, local model SHA, dataset, Python NumPy/PyTorch environment, actual Vivado/XSim tools and license, enough space. Verify model architecture and original preprocessing/quantization. Do not invent substitute data/model. Preserve legacy tests; run representative legacy baseline smoke if available, record if blocked; old recovery/fault cases are not new required behavior.
- Python unit: independent instruction encoding vectors in 01 plus labels/pseudo LI boundary, all 24 real instructions accepted; HEX pack/unpack signed byte ordering, padding and memory allocation, reference matches existing sample0 golden. Verify `manifest` + generated addresses and no overlap.
- ISA smoke: one/few programs cover LUI, ADD/ADDI (+/− and wrap), AND/ANDI, OR/ORI, SLLI/SRLI, BEQ/BNE taken/not taken, JAL link, x0 no-write, LW/SW aligned data, CSRW/CSRR/SETI incl packed CSR width and sign immediate, END. Observable GPR/CSR values via SW/CSRR+SW; no internal probes. Observe external fetch order if needed. Minimal valid cases, not all combinations.
- DMA smoke: LOAD then STORE known words of length 4 and multiword, test A/B and representative W/Bias (all banks via model loads); confirm no repeated/omitted write, final word, bank read selection. GEMM smoke: small valid K≥8, N nonmultiple of 4 and/or multiple groups, bias/shift/activation, signed saturation and padding, valid nonzero base/offset case if practical. ARGMAX signed/tie and 1/10 or across word boundaries; output via SW; no extra engine tests for illegal lengths. Integrated small DMA→GEMM→ARGMAX→STORE. Existing datapath leaf regressions retained if practical (new end-to-end TB restriction applies to new top). Timer smoke via TSTART/TSTOP, CSRR/SW count; known N+2 DMA each direction, GEMM schedule E−S (02), exclude ARGMAX/scalar, reset TSTART clears; do not run billions of cycles for overflow. No runtime exception checks.

## 1. Required model scenarios, sequential gates
All use original fixed model and same quantized weight set, MNIST **test** sample IDs 0..count−1 in order. A new scenario invocation resets once, loads weights/bias once, streams images through one program and ends once. Never reload same model per image. Save required layers to DMEM before they are overwritten. FC3 saved physically 12 bytes (10 logits+2 zero pads). ARGMAX stored 32-bit per image. Reference independent arrays generated for all images; comparator only requires specified outputs per gate.
| Gate | Count | Outputs required | PASS |
|---|---:|---|---|
| V1 | 1 | FC1,FC2,FC3,ARGMAX | all 512+128+12 bytes and argmax word equal |
| V5 | 5 | FC1,FC2,FC3,ARGMAX | every layer byte + every argmax equals |
| V20 | 20 | ARGMAX only | 20/20 equal |
| V100 | 100 | ARGMAX only | 100/100 equal |
| V200 | 200 | ARGMAX only | 200/200 equal |
| V200F | 200 (same IDs) | FC3+ARGMAX | 200×12 bytes incl zero padding, 200/200 argmax equal |
No routine FC1/FC2 stores at V20+, no required 1000/10000 overnight. If argmax mismatch, generate diagnostic full-layer program for original failed ID(s), preserve previous failing artifacts; if V200F fails compare all layers on failed IDs. Identify first differing layer, input/layout/CSR/ALU/codegen/RTL root cause; fix and rerun original failing scenario plus required regressions. If final argmax and FC3 pass, proceed to implementation, no full deep verification of all 200 required. Sample0/5 deep validation must stay passing. Reference vs labels accuracy separately reported (not target accuracy guarantee), no masking. Timer off, no bulk waveform by default. Save optional diagnostic waves only on failures. Do not require overall Start→Done time; timeout only. Support user-initiated 1k/10k argmax/accuracy later via documented CLI.

## 2. FPGA gates
- Top `npu_top`, internal SRAM + controller/datapath, exclude external IMEM/DMEM, TB, behavioral models and golden files. `xc7a100tcsg324-1`, 10 ns clock, OOC. Keep original FPGA constraints regarding no board pins/IO timing: internal register paths only; explicitly report unconstrained IO/reset and scope, do not claim board timing.
- Run actual Vivado synthesis, opt_design/place_design/route_design, check synthesis and post-route DRC, no fatal errors, real routing complete. Use `report_utilization`, `report_timing_summary` (setup/hold), top critical paths, BRAM/DSP mapping, clock constraints/check_timing, logs and routed DCP. Setup post-route WNS >= 0 ns (TNS=0, no violating endpoints); hold must not introduce violations (report WHS/THS where available). No missing clock or unjustified false/multicycle paths, no weakening 100MHz. OOC excludes board I/O, so report any unconstrained endpoints; internal required paths constrained. Resources fit target; report LUT/FF/RAMB36/RAMB18/BRAM tile equivalents/DSP counts, percentages vs device. Baseline 135 BRAM tiles; prior main result ~104 RAMB36 +11 RAMB18 (109.5 equivalents ~81.11%) is reference only, not pass threshold. Preserve expected block RAM mapping/depth and report any unexpected LUTRAM.
- If timing fails, inspect path(s), optimize within 01/02 contracts (e.g. remove redundant logic, use cursor, balance/control register logic without changing nine-state interface/legacy schedule, synthesis/physical optimization). Rerun functional gates after RTL change, re-synth/re-route. Record strategy/seed and metrics. No claiming closure based on synthesis WNS only.
- Power analysis LAST after functional and routed timing pass: `report_power` from routed design, state vectorless/default activity or documented valid activity, report dynamic/static/total and assumptions. Not a numeric acceptance threshold. If tool unavailable, mark blocked/not run, not fabricated.

## 3. Final acceptance
Required: complete source + Python scripts/assembler + runnable scenarios + tests; all smoke and V1/V5/V20/V100/V200/V200F PASS; no test changed to fit DUT; 100MHz OOC post-route WNS>=0, no setup/hold violations in constrained internal paths, resource fit, power report generated or explicitly blocked with no claim of full completion; no push. Provide exact test commands, IDs, hashes, results/counts, routed reports/log paths, final branch/commit, decisions, and any limitations in 10. A failure or unrun gate is NOT PASS; if retry budget exhausted report partial status.
