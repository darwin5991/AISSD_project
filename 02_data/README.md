# 프로젝트 데이터

프로젝트 데이터셋은 `raw/`에 보관하고 Git에는 올리지 않습니다. 기존 저장소 루트의 `../../data/`를 재사용할 경우 모델 설정에 실제 경로를 명시합니다.

데이터를 준비하면서 다음을 기록합니다.

- 데이터셋 이름, 공식 출처, 다운로드 방법, 파일 해시
- train·validation·test 구분과 calibration 데이터 선택 기준
- 정규화·flatten 순서 등 입력 전처리
- 평가 샘플 ID, 샘플 수, seed

양자화 보정용 데이터와 최종 정확도 평가용 데이터의 역할을 구분합니다. 검증용 HEX와 기대 출력은 `../07_runs/<실행 ID>/vectors/`에 생성하고, 사용한 샘플과 전처리는 해당 실행 manifest에 기록합니다.
